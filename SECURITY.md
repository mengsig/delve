# Security

Please report suspected vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/mengsig/delve/security/advisories/new). Include affected versions, reproduction steps, impact, and any proposed mitigation. Please do not disclose the issue publicly until maintainers have had an opportunity to investigate and coordinate a fix.

The latest release is the supported version. See [dependency security notes](docs/security.md) for the current audit and [README](README.md#security-model) for the application security model.
